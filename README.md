# Support Before Score: Auditing Few-Shot Conformational Population Prediction

Anonymous code and data companion for the ICLR 2027 submission.

## Abstract

Few-shot conformational-population benchmarks can produce precise cross-validated errors without showing whether a held-out effect has support in the encoding, survives the state definition, or is available to the representation-selection procedure. We introduce a support-first evaluation framework and apply it to matched three-state NMR panels for the Abl1 and Src kinases. Pairwise support analysis finds exact and near feature collisions between mutations with different population shifts. In Abl1, sequence features resolve a collision created by site markers: a retrospectively fixed, fold-local ESM-2 PCA representation gives a same-environment GPU-reproduced MAE of 0.148, versus 0.233 for the training mean, but choosing among representations inside each fold gives 0.262. In Src, pooling to an active/non-active endpoint removes the E1--E2 contrast, while retained active--non-active performance is model-dependent. In the orthonormal contrast basis, the E1--E2 axis MAE exceeds the retained active--non-active axis MAE in all ten CLR rows and in 13 of 15 rows overall. A controlled three-state factorial experiment uses 12,000 generated datasets and yields 72,000 metric records: it shows the equal-prediction reference for an exact collision, pooling hides an independently varied fine-state contrast, and naive selection grows more optimistic as the candidate set expands. A structural case exposes a separate estimator dependency: restricting the alignment to the alphaC-helix region moves the fraction assigned I1-like under the stated rule from 0/840 to 451/840. We calibrate the audit itself against the planted mechanisms and preregister quantitative diagnostic predictions, so the framework's out-of-sample claims will be scored rather than asserted. We therefore define a reporting order that establishes local support, retained contrasts, representation selection, and structural assignment before aggregate error is interpreted.

## Prospective v3

V3 freezes one primary endpoint for a new K=3 panel with at least eight mutants: `facebook/esm2_t33_650M_UR50D` residue embedding differences, sum aggregation over multi-site substitutions, PCA fit only on outer-training residue rows with dimension `min(20,n_train-1)`, and LowRankCDST (rank 2, hidden 32, 800 Adam epochs, learning rate 0.005, weight decay 0.0001, five fixed seeds). The identical-fold training mean is the primary comparator. FoldX and all alternative predictors are secondary.

The data custodian keeps mutant populations private, executes the frozen package once, and releases sealed outputs at one reveal. A negative primary result is retained; no post-reveal tuning, threshold changes, row deletion, or secondary promotion is allowed. See `prospective_validation/v3/README.md`.
